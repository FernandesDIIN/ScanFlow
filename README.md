# ScanFlow

O **ScanFlow** é uma extensão para Adobe Photoshop que reúne ferramentas
para a edição de mangás, manhwas e manhuas em um só fluxo de trabalho.

A extensão foi criada para ajudar nas etapas de detecção de texto,
reconhecimento por OCR, limpeza da arte, retoque e typesetting, permitindo
trabalhar diretamente com as páginas no Photoshop.

## Funcionalidades

### Detecção e OCR

- Identificação de áreas de texto para preparar a edição.
- Reconhecimento de texto por OCR para auxiliar na leitura do conteúdo
  original.
- Revisão das áreas e dos resultados antes de continuar o trabalho.

### Limpeza e retoque

- Ferramentas para remover textos e preparar as áreas para receber as
  falas traduzidas.
- Processamento com modelos locais, conforme os componentes incluídos
  no pacote.
- Recursos de revisão e retoque para corrigir o resultado.

### Typesetting

- Preparação e aplicação dos textos nas áreas correspondentes da página.
- Ferramentas para organizar o trabalho de typesetting dentro do Photoshop.
- Revisão do resultado antes da finalização.

O ScanFlow **não inclui tradução automática**. A tradução das falas é
feita separadamente e depois utilizada no fluxo de edição.

## Requisitos

- Windows.
- Adobe Photoshop com suporte a extensões CEP.
- Espaço suficiente para os arquivos e modelos incluídos no pacote.

Consulte os documentos incluídos na versão baixada para verificar
requisitos adicionais e a compatibilidade com sua versão do Photoshop.

## Instalação

1. Baixe o pacote completo na seção **Releases**.
2. Extraia o ZIP.
3. Feche o Photoshop.
4. Execute `Instalar.cmd` e siga as instruções exibidas.
5. Abra novamente o Photoshop e procure o ScanFlow no menu de extensões.

Mantenha juntos a pasta `ScanFlow`, os arquivos do instalador e os demais
componentes incluídos no pacote.

## Fluxo de trabalho

1. Abra a página no Photoshop.
2. Use as ferramentas do ScanFlow para identificar as áreas de texto.
3. Execute o OCR e revise o conteúdo reconhecido.
4. Limpe as áreas necessárias e faça os retoques.
5. Prepare a tradução separadamente e aplique os textos na página.
6. Revise o resultado antes de salvar ou exportar.
