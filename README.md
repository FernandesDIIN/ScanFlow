# ScanFlow

O ScanFlow é uma extensão para Adobe Photoshop voltada ao fluxo de edição
de mangás, manhwas e outras imagens sequenciais.

O projeto reúne ferramentas para trabalhar com recortes e textos durante
o processo de edição, com recursos de processamento local.

## Download

Baixe o pacote completo na seção **Releases** deste repositório.

O pacote inclui a extensão, os arquivos necessários para instalação e o
documento de créditos dos componentes utilizados.

## Instalação no Windows

1. Baixe e extraia o pacote completo.
2. Feche o Photoshop.
3. Execute `Instalar.cmd` e siga as instruções.
4. Abra novamente o Photoshop e procure o ScanFlow no menu de extensões.

Mantenha as pastas e os arquivos do pacote juntos durante a instalação.

## Arquivos e créditos

Consulte `CREDITOS.txt` para informações sobre os componentes e modelos
incluídos. Cada componente pode possuir sua própria licença e condições
de uso.
